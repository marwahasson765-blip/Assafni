# Asaafni – أسعفني

تطبيق Flutter عربي RTL يعمل محلياً باستخدام SQLite (`asaafni_database.db`) لإدارة طلبات سيارات الإسعاف في مدينة عطبرة. لا يستخدم Firebase أو MySQL. الخرائط وGPS ميزات اختيارية؛ يمكن إرسال الطلب بالإحداثيات أو العنوان اليدوي عند عدم توفر الإنترنت.

## التشغيل
1. ثبّت Flutter 3.24+ وAndroid Studio.
2. من مجلد المشروع شغّل `flutter pub get` ثم `flutter run`.
3. لبناء APK: `flutter build apk --release`.

## الحسابات التجريبية
- مستخدم: `0912345678` / `123456`
- سائق: `0999999999` / `123456`
- مدير: `admin@asaafni.local` / `admin123`

تظهر البيانات بوضوح على أنها تجريبية ويمكن إعادة ضبطها من لوحة المدير. النسخة المحلية لا تزامن بين أجهزة مختلفة؛ ذلك يحتاج خادماً مشتركاً في إصدار لاحق.
